# Deployment Notes

## What is built
- static Rural Haven site scaffold in `property-os/app/`
- seller intake section
- investor intake section
- opportunity board section
- contact section
- Airtable env placeholders in `.env.example`

## Run locally
From `property-os/`:
- `npm run dev`

Then open:
- `http://localhost:8080`
