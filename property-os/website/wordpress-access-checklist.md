# When WordPress Access Is Needed

WordPress access is only needed if Nathan wants the public site launched on WordPress.

## If using WordPress, needed items
- WordPress admin login
- hosting access if theme/plugins must be installed
- domain/DNS access if not already pointed correctly

## If not using WordPress
We can build the site as a lighter custom front-end and only need:
- domain/DNS access
- hosting or deployment target

## Recommendation
Do not wait on WordPress to design the system.
Build the structure first, then deploy to the chosen platform.
