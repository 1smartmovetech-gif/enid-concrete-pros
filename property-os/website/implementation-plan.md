# Rural Haven Implementation Plan

## Chosen direction
Build a lean hybrid system:
- Airtable = internal operating system
- ruralhaven.co = public website
- WordPress only if needed for marketing pages or blog/SEO later

## Phase 1 - Foundation
- finalize sitemap
- finalize brand copy
- finalize Airtable schema
- build seller intake form spec
- build investor intake form spec

## Phase 2 - Internal OS
- create Airtable base
- create core tables and views
- add status options and automations
- create sample records

## Phase 3 - Public Site MVP
- build homepage
- build seller page
- build contact page
- build properties page shell
- connect forms to Airtable

## Phase 4 - Operationalization
- create follow-up automations
- create listing publishing workflow
- create dashboard for active deals
- add buyer list capture

## Access needed later

### Needed to launch public site
- DNS or hosting access for `ruralhaven.co`
- preferred platform access if using WordPress or hosting panel

### Needed to connect backend
- Airtable base access or API credential path

## Recommended immediate next build sequence
1. Stand up the Airtable base structure
2. Build website wireframes/content in the workspace
3. Once access is provided, deploy the public site
