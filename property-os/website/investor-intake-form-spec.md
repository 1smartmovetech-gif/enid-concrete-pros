# Investor / Buyer Intake Form Spec

## Goal
Capture buyer criteria so Rural Haven can build a usable investor list.

## Fields
- Full Name
- Phone
- Email
- Markets of Interest
- Property Types
- Preferred Strategy
- Price Range
- Cash or Financing
- Notes
- Consent to be contacted

## Airtable destination
Table: `Contacts` or `Buyers` if a dedicated table is added later

## Tags to derive
- market tags
- budget tags
- strategy tags
- buyer type
