# Daily Review

Run this once per day.

## 1. Inbox Sweep
- Capture all new leads
- Remove duplicates
- Promote real leads into property records

## 2. Pipeline Check
- Review every active stage
- Make sure each property has a next action
- Update stalled deals

## 3. Follow-Up Queue
- Who needs a call, text, email, or message today?
- What is overdue?

## 4. Offers and Decisions
- Which deals need underwriting?
- Which deals need an offer?
- Which deals should be killed quickly?

## 5. Marketing / Dispo
- Which listings or owner-finance properties need promotion?
- Which buyers need updates?

## 6. End-of-Day Rule
Before stopping, every active property should show:
- current stage
- next action
- target date
- last updated date
