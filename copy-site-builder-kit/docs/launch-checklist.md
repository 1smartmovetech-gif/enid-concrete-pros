# Launch Checklist

- Confirm niche, city, domain, and phone number
- Replace all placeholders
- Review every page for false claims
- Review every page for duplication
- Confirm internal links work
- Confirm one H1 per page
- Confirm title tags and meta descriptions are unique
- Confirm forms route correctly
- Confirm mobile layout is clean
- Confirm sitemap exists
- Confirm robots settings allow indexing
- Confirm no fake testimonials appear
- Confirm no fake address appears
- Confirm disclaimer appears where needed
- Export backup package
