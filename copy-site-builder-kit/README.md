# Copy Site Builder Kit

A reusable local lead-gen build kit based on Nathan's prompt and the structure patterns seen on autoglassnola.com, without copying their wording or false business claims.

## Purpose
Use this kit to spin up clean local service sites that are:
- lightweight
- sellable to local operators
- safe from fake-claim issues
- structured for local SEO and lead capture

## Included
- `docs/site-build-spec.md`
- `docs/page-inventory.md`
- `docs/launch-checklist.md`
- `templates/wordpress-page-brief-template.md`
- `templates/seo-sheet.csv`
- `prototype-site/index.html`

## Notes
- This kit mirrors the useful structure of a strong local service site: homepage, service pages, service area, FAQs, contact, and educational pages.
- It does **not** copy competitor copy.
- It uses independent-guide positioning unless a real operator is assigned.

## Best use
1. Pick city + niche
2. Fill in the prompt variables
3. Generate page briefs
4. Build pages in WordPress or use the prototype as the content/design model
5. Connect call tracking and forms
