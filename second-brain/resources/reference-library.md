# Reference Library

Nathan wants shared books, PDFs, docs, and other reference material to be stored, indexed, summarized, and organized for reliable later use.

## System

Primary library location:

- `reference-library/`

Core files:

- `reference-library/index/master-index.md`
- `reference-library/ingestion/PROCESS.md`
- `reference-library/ingestion/source-template.md`

## Operating rule

A source should not be treated as durable reusable knowledge until it has been:

1. captured
2. stored or linked
3. indexed
4. summarized

## Future workflow

When Nathan shares reference material:

- save the file or create a durable link record
- add it to the master index
- summarize it
- extract playbooks or topic notes if it is high value
