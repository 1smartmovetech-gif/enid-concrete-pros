# Second Brain

This folder is the structured layer of memory for Obsidian and OpenClaw.

## Purpose

Use this directory for durable, linkable notes that benefit from graph structure:

- `people/` — people, collaborators, and recurring contacts
- `projects/` — active and archived projects
- `areas/` — ongoing life/work domains
- `decisions/` — important choices and why they were made
- `inbox/` — rough captures to sort later
- `resources/` — reference material worth keeping

## Relationship to existing memory

- `memory/YYYY-MM-DD.md` = raw daily log
- `MEMORY.md` = curated long-term memory
- `second-brain/` = structured notes that can link across topics

## Linking conventions

Prefer Obsidian wiki-links when a note deserves a stable home:

- `[[second-brain/projects/openclaw]]`
- `[[second-brain/people/nathan-laughlin]]`
- `[[second-brain/decisions/obsidian-memory-structure]]`

Keep note names lowercase with hyphens for predictability.

## Workflow

1. Capture rough notes in daily memory files or `inbox/`
2. Promote recurring facts into `people/`, `projects/`, `areas/`, or `decisions/`
3. Distill the most durable facts into `MEMORY.md`
4. Cross-link related notes so the graph stays useful
