# Deal Folder Template

Create one folder per property using this structure.

## Folder Naming
`[STATE]_[CITY]_[STREET-ADDRESS]_[STATUS]`

Example:
`IN_Evansville_719-Jackson-Ave_Underwrite`

## Subfolders
### 01_intake
- lead source screenshots
- seller info
- basic intake sheet
- initial notes

### 02_underwriting
- address analyzer
- comps
- repair estimate
- tax snapshot
- insurance estimate
- underwriting notes

### 03_title
- title commitment
- lien search
- legal description
- vesting info
- probate or entity documents if relevant

### 04_acquisition_docs
- purchase agreement
- addenda
- assignment docs if applicable
- earnest money proof
- closing statement
- deed

### 05_funding
- lender info
- loan agreement
- promissory note
- mortgage or deed of trust
- wire confirmations
- lender title policy

### 06_property_condition
- photos
- inspection
- contractor bids
- utility notes
- occupancy notes

### 07_disposition
- listing copy
- marketing photos
- buyer inquiries
- showing notes
- pricing strategy

### 08_buyer_docs
- application or buyer intake
- ID and verification docs
- signed disclosures
- resale agreement
- note / contract for deed / mortgage docs
- insurance proof

### 09_servicing
- ledger
- payment instructions
- late notices
- tax tracking
- insurance tracking
- payoff requests

### 10_default_enforcement
- notices
- cure letters
- attorney correspondence
- recovery checklist

### 11_final_summary
- final numbers
- profit summary
- lessons learned
- timeline recap

## Deal Dashboard Fields
Track these in one summary file per property:
- address
- source
- ask price
- contract price
- all-in basis
- exit type
- target resale price
- target down payment
- target monthly payment
- actual down payment
- actual monthly payment
- funding source
- title status
- servicing status
- risk grade
- current stage
- next action

## Rule
If a document matters, save it in the folder the same day.
Do not let critical deal knowledge live only in texts, calls, or memory.
