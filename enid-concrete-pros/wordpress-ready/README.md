# WordPress-Ready Package

This folder is the portable WordPress-ready implementation package for Enid Concrete Pros.

## What it includes
- lightweight custom theme scaffold
- WordPress page content source files
- import mapping notes
- recommended plugin list
- deployment instructions

## Important
A live WordPress runtime was not installed on this server because PHP and MySQL are not available here right now.

So this is the cleanest deployable handoff package short of a live WP host install.
