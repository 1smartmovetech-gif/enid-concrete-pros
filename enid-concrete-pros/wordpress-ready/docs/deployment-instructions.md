# Deployment Instructions

## What you need
- a WordPress host with PHP + MySQL
- admin access to install a theme and plugins

## Steps
1. Install WordPress on the target host.
2. Zip the `theme/enid-concrete-pros/` folder and upload it as a custom theme.
3. Activate the theme.
4. Install the recommended plugins.
5. Create the pages listed in `docs/page-list-and-urls.md` from the main package.
6. Paste in the content from `site/full-pages/`.
7. Upload the images from `site/assets/`.
8. Set the menus.
9. Add SEO titles/meta from `docs/seo-titles-and-meta-descriptions.csv`.
10. Replace placeholders and test forms.
