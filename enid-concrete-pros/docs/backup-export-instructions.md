# Backup / Export Instructions

## Recommended options
1. Use All-in-One WP Migration export after final QA.
2. Export the theme customizer settings if used.
3. Export SEO metadata if the SEO plugin supports it.
4. Save a CSV copy of the keyword and metadata sheet.
5. Keep media assets in a clean `/uploads/enid-concrete-pros/` structure.

## Rebranding handoff
- change logo
- change phone number
- change email
- change form notification destination
- update disclaimer and footer ownership if the site is sold or assigned
