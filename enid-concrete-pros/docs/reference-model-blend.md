# Reference Model Blend

## How the Enid site should be built

### Use autoglassnola.com for:
- local lead-gen site structure
- simple service-business layout
- phone-first conversion behavior
- city + niche clarity
- service page orientation

### Use rentlocalsites.com for:
- simplicity philosophy
- fast-loading bias
- anti-clutter decisions
- conversion-first minimalism
- willingness to keep the site plain if plain works better

## Resulting build style
The Enid site should be:
- simple
- fast
- direct
- phone-forward
- easy to understand
- not overdesigned
- focused on service intent, not storytelling

## What to avoid
- heavy design flourishes
- generic AI fluff
- extra sections that do not help ranking or conversion
- fake trust signals
- unnecessary technical complexity
