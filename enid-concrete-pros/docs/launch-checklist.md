# Launch Checklist

- Replace phone, email, address, logo, and form destination placeholders
- Test all forms and call buttons
- Confirm sitemap is active
- Confirm robots/index settings allow indexing
- Confirm no placeholder copy remains beyond approved placeholders
- Review every page for duplicate content
- Review all service pages for unique FAQs and intros
- Review schema output for accuracy
- Compress images and confirm alt text
- Test mobile layout on homepage and service pages
- Run basic speed test
- Export backup package
- Complete dry-run review before publishing
