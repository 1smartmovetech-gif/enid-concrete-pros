# Theme and Plugin List

## Recommended theme
- Twenty Twenty-Five, or GeneratePress if a classic lightweight theme is preferred

## Recommended plugins
- SEO: Rank Math or Yoast SEO
- Forms: WPForms Lite or Fluent Forms
- Schema support: built through SEO plugin, only where factual
- Caching/performance: WP Super Cache or LiteSpeed Cache if server supports it
- Image compression: ShortPixel or Smush
- Backup/export: All-in-One WP Migration or UpdraftPlus
- Security/basic hardening: Limit Login Attempts Reloaded

## Avoid
- heavy visual page builders
- fake review/testimonial plugins
- unnecessary animation or popup bloat
