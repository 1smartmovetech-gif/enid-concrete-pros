# Contract Stack Matrix

This is the document map for slow flip and related real estate deals.
It is not a substitute for attorney review.
Use it to know what belongs in the file and why.

## 1. Acquisition, Direct Purchase
### Core docs
- Purchase Agreement
- Addenda and amendments
- Seller disclosures required by state
- As-is addendum if applicable
- Inspection or due diligence contingency if used
- Title / escrow instructions
- Closing statement or settlement statement
- Deed

### Purpose
- establishes purchase terms
- allocates closing responsibilities
- documents disclosure and condition position
- transfers ownership

## 2. Acquisition, Wholesale / Assignment
### Core docs
- Purchase Agreement with assignment rights if intended
- Assignment Agreement
- Earnest money proof
- Inspection / due diligence provisions
- Closing instructions
- Assignment fee disclosure where required

### Purpose
- controls the property contractually
- transfers contract rights to end buyer where allowed
- documents economics and timing

## 3. Funding, Private Money
### Core docs
- Loan Agreement
- Promissory Note
- Mortgage or Deed of Trust, recorded
- Personal guaranty if used
- Lender title insurance policy
- Hazard insurance evidence
- Payoff instructions
- Wire instructions and funding memo

### Purpose
- defines economic terms of loan
- gives lender enforceable repayment rights
- secures lender with recorded collateral
- documents insurance and title protection

### Critical note
Do not rely on a loan agreement alone. Use the actual note and recorded security instrument.

## 4. Resale, Cash Buyer
### Core docs
- Purchase and Sale Agreement
- Seller disclosures required by state
- As-is acknowledgement if applicable
- Closing statement
- Deed

### Purpose
- documents straightforward resale
- allocates risk and disclosure obligations

## 5. Resale, Slow Flip / Owner Finance
Structure varies by state and attorney advice.
Possible structures include contract for deed, installment land contract, or note plus mortgage/deed of trust.

### Core business docs
- Purchase and Sale Agreement
- Financing addendum or seller-finance terms summary
- Contract for Deed OR Promissory Note + Mortgage/Deed of Trust
- Memorandum of Contract if appropriate and attorney-approved
- Deed in escrow if attorney/title company recommends
- Payment servicing authorization
- Insurance requirements addendum
- Tax responsibility / escrow procedure addendum
- Maintenance and occupancy provisions
- Default and cure notice procedure
- Payoff request procedure
- Assignment restriction if desired

### Purpose
- documents payment stream and collateral rights
- explains who pays taxes, insurance, and maintenance
- defines late/default process
- creates enforceable file for collection or recovery

## 6. Compliance / Disclosure Layer
Add as required by property type, age, and state.
Examples:
- Lead paint disclosure
- Property condition disclosure
- Mold disclosure
- Radon disclosure
- Septic / well disclosures
- Floodplain disclosures
- HOA disclosures
- Investor / business-purpose acknowledgements when appropriate

### Purpose
- reduce disclosure risk
- comply with state and federal requirements

## 7. Servicing Layer
### Core docs / tools
- Payment ledger
- Welcome letter / payment instructions
- Coupon book or portal instructions
- Late notice templates
- Annual statement process
- Insurance tracking checklist
- Tax tracking checklist
- Payoff statement template

### Purpose
- makes post-close management systematic
- preserves evidence if default occurs

## 8. Default / Enforcement Layer
This should be reviewed with local counsel before needed.

### Core docs / templates
- Notice of default
- Notice of right to cure
- Acceleration notice if applicable
- Demand letter
- Forfeiture or foreclosure checklist by state
- Property recovery / turnover checklist
- Reinstatement letter template
- Payoff quote template

### Purpose
- avoid improvising when a deal goes bad
- preserve timeline and legal compliance

## 9. Recording Matrix
For each state and structure, decide:
- what gets recorded
- where it gets recorded
- who records it
- when it gets released or satisfied

Common recorded items may include:
- deed
- mortgage / deed of trust
- memorandum of contract
- release / satisfaction on payoff

## 10. State-Specific Review Points
Attorney review is required for:
- land contract enforceability
- cure periods and default notices
- forfeiture vs foreclosure remedies
- disclosure requirements
- late fee limits
- usury rules
- electronic signature and remote closing rules
- recording strategy

## Operator Rule
Every closed deal should have a complete digital file with signed copies, recorded copies, settlement statements, insurance evidence, and servicing setup.
