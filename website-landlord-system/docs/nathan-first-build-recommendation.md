# Nathan First Build Recommendation

## Best first niche
**Junk removal**

Why:
- direct fit with the transcript example
- easy call-driven conversion path
- easy to understand for local business operators
- simple site structure
- easy to prove lead value quickly

## Best first market approach
Do not start with 10 sites.
Start with:
- 1 niche
- 1 city
- 1 frontend site
- 1 GHL backend flow
- 1 tracking number
- 1 operator outreach script

## Suggested first stack
- Frontend: static site
- DNS: Cloudflare
- Hosting: Cloudflare Pages or Netlify
- Backend: GoHighLevel master sub-account
- Tracking: GHL phone number
- Form handling: GHL embedded form or webhook

## What to build first
1. homepage
2. thank-you page
3. one extra service page
4. GHL pipeline
5. GHL form
6. missed-call text back
7. new lead notification

## What to avoid right now
- overbuilding a fancy brand
- multiple cities at once
- too many service categories
- paying for expensive design before validation
- complicated automations you do not need yet

## Clean rollout sequence
1. build the site
2. connect form and call tracking
3. test lead capture
4. get it indexed
5. start outreach to operators
6. close first rent/lead deal
7. clone what works
