# Frontend Deployment Guide

## Best first option
Use static sites.

Why:
- fast load speed
- low hosting cost
- easy to duplicate
- low plugin risk
- clean ownership

## Basic folder structure
- index.html
- thank-you.html
- /assets/
- /service-pages/

## What each frontend needs
- clear headline with city + service
- call button above the fold
- form section above the fold or mid-page
- service bullets
- FAQ
- local proof or service area section
- trust copy
- footer with consistent NAP style if you use one

## Embed options

### Option A: GHL form embed
Fastest.

### Option B: custom form posts into GHL webhook
More flexible and cleaner design.

## Hosting suggestions
- Cloudflare Pages
- Netlify
- VPS with Nginx if you want full control

## SEO notes
- keep pages lightweight
- use unique copy per city and niche
- avoid cloning exact text across every market
- add real service area content
- add unique FAQs and offer details

## Scaling pattern
1. build one winning site
2. template the structure
3. change city, niche, copy, phone, and schema
4. deploy new property in under 1 hour
