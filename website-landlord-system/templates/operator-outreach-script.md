# Operator Outreach Script

## Simple text / email version

Hey, I built a local website that is already set up to target {{service}} leads in {{city}}. I’m looking for one operator to handle the calls.

The idea is simple: when leads come in, they route to you. If it looks like a fit, we can do either a flat monthly arrangement or pay-per-lead.

If you want, I can show you the site and how the lead flow works.

## Call version

"I built a local lead-gen site for {{service}} in {{city}} and I’m looking for one company to take the incoming calls. I’m not selling SEO services. I’m talking about actual lead flow. If I send you calls for exactly what you do, would you be open to testing that?"

## Follow-up after interest

"Great. I can show you the site, the phone flow, and how leads get routed. We can start simple with either a test period, pay-per-lead, or a monthly flat rate."
