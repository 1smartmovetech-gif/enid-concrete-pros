# Website Landlord System

A practical setup for local SEO lead-gen sites on the frontend and GoHighLevel as the backend operating system.

## Stack

### Frontend
- Static HTML/CSS sites for speed and low cost
- Optional later upgrade to WordPress or Webflow if needed
- One domain per city+niche site or subfolders on a hub domain

### Backend
- GoHighLevel for:
  - forms
  - CRM / pipeline
  - missed call text back
  - automations
  - calendars if needed
  - reporting snapshots
  - call tracking numbers

## Recommended first build

Start with one niche, one city, one simple call-driven offer.

Best first options:
- junk removal
- tree service
- epoxy flooring
- pressure washing
- dumpster rental

## My recommendation for Nathan

1. Launch a static frontend site first
2. Connect forms and tracking into GoHighLevel
3. Prove calls/leads
4. Then clone the system into more cities and niches
