# Website Landlord Lab

Built from the actual Pages transcript OCR.

## Core model from the transcript

- Build a simple website for a specific service in a specific city
- Rank it with local SEO
- Put a tracking phone number on it
- Let calls go to voicemail or capture data until a local business partner is lined up
- Rent the lead flow or sell the leads to the operator

## Concepts built

1. `junk-removal-austin/`
   - Direct transcript-style example
   - Strong first proof-of-concept build

2. `epoxy-flooring-tulsa/`
   - Higher-ticket local service niche
   - Good for fewer, better leads

3. `pool-removal-phoenix/`
   - Less crowded specialty niche
   - Better fit if you want unusual supply/demand gaps

## My recommendation

Start with **junk removal** or another ugly-but-simple service category:

- junk removal
- tree service
- dumpster rental
- epoxy flooring
- concrete coating
- deck staining
- pressure washing
- small demolition

These usually have:
- obvious buyer intent
- fast phone-call conversion
- simple local landing-page structure
- business owners who understand lead value quickly

## Best next move

Turn one of these into a real operator-ready asset with:
- service pages
- city pages
- call tracking placeholder
- form capture backend
- Google Business Profile support plan
- basic SEO content cluster
