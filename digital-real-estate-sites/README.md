# Digital Real Estate Lab

First-pass website concepts built from the distressed-property / title-problem niche research in `logan_fullmer_research.md` and related notes.

## Included prototypes

1. `heir-hunter/`
   - Seller-facing inherited property lead-gen site
   - Best for direct acquisitions and local SEO clones

2. `probate-property-alerts/`
   - Investor-facing subscription / info-product site
   - Best for recurring revenue and data-product positioning

3. `title-problem-scorer/`
   - Interactive tool / lead magnet
   - Best for authority-building and investor funneling

## Recommendation

If the goal is to make money fastest, start with **Heir Hunter**.

Why:
- strongest pain-driven offer
- easiest to localize by city/market
- closest to direct deal flow
- can plug into Nathan's existing property/investor stack quickly
