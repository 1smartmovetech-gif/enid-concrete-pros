# Vanquish Trading Journal, Polished

Created from your existing `Vanquish_Options_Trading_Journal.xlsx`.

## What changed
- Rebuilt the **Trades** sheet with cleaner fields for futures journaling
- Added automatic formulas for:
  - Risk ($)
  - P/L ($)
  - P/L in R
  - Win/Loss tagging
- Added stronger **Account** tracking for:
  - trailing high
  - current drawdown
  - cushion left
  - status alert
- Added a simple **Dashboard** sheet with headline stats
- Added a **Strategies** sheet so each setup has its own playbook
- Added dropdowns for sessions, direction, emotions, grading, rule-following, and mistake type
- Added conditional formatting so wins, losses, warnings, and rule breaks stand out fast

## New file
`Vanquish_Trading_Journal_Polished.xlsx`

## Suggested workflow
1. Log every trade in the **Trades** sheet
2. Update daily account values in **Account**
3. Review the **Dashboard** after each session
4. Keep only a few repeatable setups in **Strategies**
5. During weekly review, sort by:
   - setup
n   - mistake type
   - emotion before entry
   - A+ setup?

## Best use for prop-firm trading
The journal is set up to help answer:
- Which setups actually pay?
- Which sessions make you money?
- Are you breaking rules when down on the day?
- Are you sizing too large near drawdown limits?
- Which emotions show up before your worst trades?
